# SF Cinema Atlas

Interactive San Francisco film-location choropleth map and editable D3 classroom exercises.

Data: https://data.sfgov.org/Culture-and-Recreation/Film-Locations-in-San-Francisco/yitu-d5am/about_data

The deployed index.html bundles the unchanged source datasets, D3 and fonts for reliable static hosting. Download SF-Cinema-Atlas.zip for the original modular source, data provenance, audit and licenses. No external film metadata or images are added.
